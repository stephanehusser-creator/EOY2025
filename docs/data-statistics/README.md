# Data and Statistics Repository

**Purpose:** Centralized data repository for EMEA aviation market
**Status:** 🟡 In Progress
**Last Updated:** November 4, 2025

---

## Overview

This directory contains all consolidated market data, statistics, and metrics used across the EMEA Aviation Sales 2024 presentation. Data is organized by category for easy access and reference.

## Directory Structure

```
data-statistics/
├── README.md (this file)
├── market-data/          # Market size, growth, valuations
├── regional-data/        # Europe, Middle East, Africa specific data
├── industry-metrics/     # Workforce, sustainability, digital, fleet
└── raw-data/            # CSV files for analysis and charting
```

## Key Statistics Quick Reference

### Market Size
- **EMEA Infrastructure:** $1.03B (2025), CAGR 4.42%
- **MEA Aviation:** $34.43B (2025)
- **Middle East:** $28.38B (2025) → $35.19B (2030)
- **Aviation Fuels:** $12.98B (2024) → $26.12B (2030), CAGR 12.19%

### Passenger Traffic
- **Europe 2024:** 2.5B+ passengers (+7.3% YoY, +1.8% vs 2019)
- **London Heathrow:** 83.9M (+5.9% YoY, +3.7% vs 2019)
- **Dubai International:** 92.3M (2024 record)
- **Abu Dhabi:** 29M+ (record breaking)

### Growth Rates
- **Middle East Fleet CAGR:** 5.1% (2025-2035) - 82% above global 2.8%
- **MEA Cargo:** +19.9% YoY
- **Africa Capacity:** +8.6% YoY
- **Turkey:** +23.1% vs 2019
- **Small European Airports:** -34.5% vs 2019

### Industry Metrics
- **Aircraft Backlog:** 17,000 planes
- **Fleet Age:** 14.8 years average (record)
- **Workforce Gap:** 1.2M professionals needed (10 years)
- **IT Spending:** $45.3B annually (airports + airlines)
- **SAF Production:** 0.53% vs 2% required (2025)
