# Sources

This folder contains source materials, references, and resources used for the EOY2025 presentation.

## Contents

- Research materials
- Reference documents
- Data sources
- Supporting materials

## Organization

Please organize materials by topic or category:
- Create subfolders as needed
- Use clear, descriptive filenames
- Include a brief description or metadata for each source

## File Naming Convention

Suggested format: `YYYY-MM-DD-descriptive-name.ext`

Example: `2025-01-15-market-research-data.pdf`
